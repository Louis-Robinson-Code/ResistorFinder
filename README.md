# ResistorFinder-25
Year 2 Machine Vision Module Submission.
The projects aim is to locate resistors in a set dataset provided and identify their resistance levels through extracting and calculating their colour bands.

- MV_Resistor_Detection.ipynb : Main Program, used to perform the Resistor Classifaction.
- Yolo_Training.ipynb : Yolo v11s Training Script to obtain model weights.
